- **jupiter** (scientific-map): Longitude origin and direction of this map were NOT verified (the official caption could not be read). Standard cartographic orientation (east to the right, north up) is assumed; Jupiter has no fixed surface, so the only consequence is the position of the Great Red Spot in longitude.
- **earth_day** (derived): SVS states the look (cloud appearance, ocean colouring) was ART-DIRECTED for a film. Derived from Blue Marble Next Generation but not a pure scientific product.
- **earth_night** (artistic-composite): The provider states its textures are tuned and contain fictional fill; this is a stylised city-lights layer, not the NASA Black Marble product.
- **mercury** (derived): The source is an ENHANCED-colour (false-colour) product that exaggerates spectral differences. Only its luminance is used; the shader tints it to an approximate natural grey-brown (a visualisation choice). East-positive longitude is the USGS convention and is not encoded in the tags. 3.5% of this map is pure black in the source, which in a planetary mosaic means NO DATA (unimaged terrain); the renderer draws it as flat grey.

- **venus** (artistic-composite): Venus's surface is permanently hidden by cloud. Visible-light images show a nearly featureless pale-yellow disc; this texture is a stylised cloud layer. No radar surface map is drawn.
- **saturn** (artistic-composite): Saturn has no fixed surface and no authoritative global cylindrical map was obtained. This is a stylised band pattern.
- **saturn_rings** (artistic-composite): The radial extent the strip covers is not documented by the provider. - **uranus** (artistic-composite): Voyager 2 saw Uranus as a nearly featureless pale cyan-blue disc; no global map exists. This is a stylised version.
- **neptune** (artistic-composite): No global map of Neptune exists. This is a stylised version of its deep-blue appearance.
